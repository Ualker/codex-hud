## hud.toml 设计草案（未实施）

目标：替代 20+ 个 env 变量的主要配置面，env 仍可覆盖（env > file > 默认）。

- 位置：`$CODEX_HOME/hud.toml`。
- 难点：`CODEX_HUD_POSITION`/`HEIGHT`/`MOUSE` 等由 **bash wrapper**（bin/codex-hud）在 tmux 建 pane 时消费，node 端读 TOML 覆盖不到。方案：wrapper 启动时调 `node dist/print-config.js --shell` 输出 `KEY=VALUE` 行 eval 进环境（构建产物已存在才走此路径，否则回退纯 env），node 端自身直接读 TOML。
- 键名与 env 一一对应（`position`、`height`、`tool_details`、`agent_inactivity_timeout_ms`…），校验失败回落默认并在 health 行提示，与现有 env 校验行为一致。
- 分阶段：先 node 端键（tool_details、ascii、timeout 等零风险项）→ 再 wrapper 桥接（position/height）。
